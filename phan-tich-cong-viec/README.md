# MỤC LỤC PHÂN TÍCH CÔNG VIỆC
Tất cả thông tin đều mang tính tham khảo ! Hãy tìm hiểu kĩ trước khi bắt đầu.

Thư mục này chứa tài liệu phân tích chi tiết cho từng thành viên trong nhóm.

Mỗi file có cấu trúc:

- Mục tiêu phần việc.
- Vai trò trong project.
- Kiến thức kỹ thuật cần nắm.
- Quy trình thực hiện.
- Deliverables bắt buộc.
- Tiêu chí hoàn thành.
- Rủi ro và cách xử lý.
- Câu hỏi bảo vệ mẫu.
- Checklist cá nhân.

Danh sách tài liệu:

| Thành viên | Vai trò | File |
|---|---|---|
| Người 1 | Data Collection Engineer | `nguoi-1-data-collection.md` |
| Người 2 | Data Processing & Feature Engineering Engineer | `nguoi-2-data-processing-feature-engineering.md` |
| Người 3 | MobileNetV2 Engineer | `nguoi-3-mobilenetv2.md` |
| Người 4 | ResNet50 & Evaluation Engineer | `nguoi-4-resnet50-evaluation.md` |

Khuyến nghị sử dụng:

- Mỗi thành viên đọc kỹ file của mình trước khi bắt đầu làm.
- Khi làm xong mỗi phần, đối chiếu với checklist cá nhân.
- Trước khi bảo vệ, dùng phần câu hỏi bảo vệ mẫu để luyện trả lời.
- Khi viết báo cáo, lấy nội dung kỹ thuật từ các file này để diễn giải lại theo văn phong báo cáo.
